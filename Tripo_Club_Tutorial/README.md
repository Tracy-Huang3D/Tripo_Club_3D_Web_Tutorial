# Tripo Club 沉浸式 3D 网站教程

这个文件夹是一份面向零基础读者的中文 Vibe Coding 教程交付包。它以 Tripo Club Case 02 的真实代码为技术参考，但读者的练习路径从一个空文件夹开始，通过 Codex 或 Claude Code 逐章构建。

## 文件说明

- Tripo_Club_3D_Web_Tutorial.md：14 章完整教程，包含操作步骤、可复制 Prompt、可见验收标准、检查清单和故障处理。
- PROJECT_AUDIT.md：Case 02 源项目功能审计，区分 IMPLEMENTED、PARTIAL 和 NOT IMPLEMENTED。
- ASSET_CHECKLIST.md：截图与 GIF 的待录制清单。
- Images_attachments/：未来放置真实演示素材的目录。

## 如何使用

1. 先阅读 PROJECT_AUDIT.md，了解哪些效果已在参考项目中验证。
2. 从主教程第 01 章开始，不要一次把 14 个 Prompt 全部发给 Agent。
3. 每章完成后先打开本地预览，用检查清单亲自观察，再进入下一章。
4. Agent 的代码可以与参考项目不同，以可见行为和验收标准为准。
5. 准备发布教程时，根据 ASSET_CHECKLIST.md 录制真实截图和 GIF，放入 Images_attachments。

## 编辑注意

- CREATE、PLAY、CONNECT、EXPLORE 是演示概念，不代表真实 Tripo Club 活动。
- 不要把参考 ZIP 中的沙发截图当作 Tripo Club 演示。
- 不要在教程或 ZIP 中放入 API Key、环境变量、私人账号信息、node_modules 或整个 Case 02 源码。
- 当前没有可复用的 Tripo Club 截图或 GIF。教程保留了明确的相对路径占位，没有用其他项目素材或伪造动图填充。
